# Отчётность — прототип фаз 1–2

Готовый frontend-прототип по ТЗ «Отчётность — ТЗ фаз 1–2».

## Что внутри

- Dashboard
- Проекты
- Деньги и транши
- Расходы
- Создание расхода
- Двустороннее подтверждение («рукопожатие»)
- Договоры и модели оплаты
- Работы и приёмка
- Внутренняя смета
- Сквозная отчётность
- Mock data, без backend и базы данных

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Next.js (обычно http://localhost:3000).

## Технологии

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

UI-компоненты сделаны локально, чтобы прототип запускался без лишней конфигурации shadcn/ui. При необходимости shadcn можно подключить на следующем этапе.

## Важно

Это именно демонстрационный frontend-прототип. Backend, авторизация, БД, загрузка файлов, OCR/AI, Telegram-интеграция и реальные финансовые операции здесь не реализованы.
